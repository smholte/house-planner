# CLAUDE.md – House Planner (public repository)

The rules for working on House Planner are in `CLAUDE.md` of the private repository `smholte/house-planner-dev`
(with the task list and the owner's own house). A session works with both repositories side by side:
`house-planner` (this one: the app, the made-up house, the public tests, GitHub test runs) and `house-planner-dev`.
Read that `CLAUDE.md` first. Never put anything of the owner's house into this repository (`tools/ci_precheck.py`
and the house-word check of `build.py` guard it).
