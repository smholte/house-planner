# House Planner tests

Browser tests with Playwright for Python. They click and tap through the app like a person would and check the
result, on a PC-sized window (1280 × 800, mouse and keyboard) and a phone (390 × 844, touch), light and dark.

    pip install playwright pillow && python -m playwright install chromium
    python3 build.py
    python3 tests/run_all.py        (serves dist/house-planner-app on port 8765 by itself when nothing runs there)
    python3 tests/run_all.py --public    only these public tests (--private: only the owner's, see below)

On GitHub (task 0008) every push runs them in parallel groups: `.github/workflows/tests.yml`, `tools/ci_groups.py`,
`tools/ci_run.py`; the result from a chat: `python3 tools/ci_status.py --wait`.

One file at a time: `python3 tests/test_furniture.py`. Screenshots land in `tests/shots/`.
The test browser draws 3D in software (SwiftShader): slow, and it lets pictures pile up. The tests wait for it with
`still(pg)` after moving the 3D view (until the camera has stopped and the automatic exposure has settled), walk routes in quick steps from the script, and switch the soft shadows in
corners off (only `test_view3d.py` switches them on).
Set `HP_URL` to test another address, and `HP_IFC_DIR` to a folder with the builder's `.ifc` files for the IFC import
(without it test_regress imports the made-up house's IFC).

**Two example houses (task 0007a).** The public app (`python3 build.py --no-house`) has the made-up test house
(`tools/testhouse/`), the owner's build has his house. The public test files run on both: they find rooms by name
and points inside them (`room_pt`, `room_screen`), and where a number or a place differs `by_house(pg, made-up,
owner's)` picks it (`tests/common.py`). Checks of what only the owner's house has (his plot, kitchen, drawings,
documents …) are in the private tests (`house/tests/`, task 0007b), which run on his build only; they are not public.
`show_on_plan` pans the plan when a spot is under the tool bar or the small 3D view.
