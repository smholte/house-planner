HOUSE PLANNER - installable version
===================================

Everything the app stores (houses, versions, save points, drawings) stays on the
device that uses it. Hosting these files only serves the app itself.

On a PC
  Open index.html in Chrome, Edge, Firefox or Safari. Or use house-planner.html,
  which is the same app in one file.

On a phone (needs the app on a web address once)
  This folder may contain your own house as the example. To put the app on a
  public web address use house-planner-web.zip instead: the same app with only
  the made-up example house. DEPLOY.md in that zip explains
  GitHub Pages and Netlify Drop. Then:
  1. Open the address on the phone.
     - iPhone/iPad (Safari): Share > Add to Home Screen.
     - Android (Chrome): menu > Install app (or Add to Home screen).
  2. Open it from the home screen. After the first start it works without internet.
  3. Import your house file (Export > Save file on the PC, then Import on the phone).

Each person installs the app on their own device. To give someone your house,
tap Export > Share (or Save file) and send the file; they tap Import. To bring
changes from one device to the other later: Export there, then on this device
open the house and choose ⋯ > Merge a copy of this house.

Language: Settings > Language (English, Nederlands, Norsk).
Backups: the app reminds you once a week to export; on a PC with Chrome or Edge,
Settings > Backup > Choose folder writes a copy after each change.
The PDF reader for builder's drawings is built in and works offline.
